Idea.Machine

Every day a computer invents new business ideas, and every one is checked before it lands here.

1 Take an old tool that people have trusted for decades → 2 Find a job that is expensive because someone must read and decide → 3 Give the old tool judgement it never had
— ideas — industries updated — — average need

Checked by hand means a person read it and could name the nearest thing that already exists. Checked by machine means a second computer applied the same four tests. Both are shown so you know which you are reading.

Every idea had to pass four tests: nobody sells it yet, it beats how the job is done today, a real buyer would pay for it, and it works on its own without buying anything else.

The need score is how many organisations do this job and how often — how widely it is needed, not how good the idea is. It is an estimate, not usage data: nobody is using these yet.

The speed and money figures are estimates the machine produced, not measured results. Each idea carries the one result that would prove it wrong.
