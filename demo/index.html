    How it compares

    We ran it against browser-use, the most popular open-source browser agent, on 445 real tasks the agent had never seen (Online-Mind2Web and WebVoyager), with the same AI model and the same independent judge. Honest summary:

    ~3×fewer AI tokens per task, so it costs about a third as much to run
    Fastermedian task time lower on every benchmark run
    Stays on the siteanswers from the website you named, instead of wandering to others
    Evenon how many tasks it gets right, by the strict judge (36% vs 32%, not a significant difference)

    It also refuses to click a button that changed while it was deciding, and a finished task can be replayed later with no AI calls at all.

    Use it from code

    Everything the page does is a plain HTTP API. Each person gets 10 free runs.

    Start a run

    curl -X POST https://agent.172.86.85.83.sslip.io/api/v1/runs \
  -H 'content-type: application/json' \
  -d '{"website": "arxiv.org", "task": "Find the newest paper about web agents and give its title"}'

    Answer: 202 {"id": "…", "status": "queued", "links": {"self": "…", "events": "…"}}

    Get the result

    curl https://agent.172.86.85.83.sslip.io/api/v1/runs/RUN_ID

    When status is done, answer holds the result and steps every action taken. replay_script is the run as a script that repeats it with no AI calls, and cost is what the AI calls were billed: {"usd": 0.0041, "xno": 0.0114, "rate": {"usd_per_xno": 0.359, "source": "coingecko", "at": "…"}}, with the XNO rate refreshed every hour.

    Watch it live

    curl -N https://agent.172.86.85.83.sslip.io/api/v1/runs/RUN_ID/events

    Server-sent events: status, step, frame (the live browser screen, a JPEG, several times a second) and done.

    Other endpoints

    • GET /api/v1/quota → {"free_runs_left": 10}
    • GET /health → {"ok": true, "running": 0, "queued": 0}
